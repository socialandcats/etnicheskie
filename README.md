# Этнические отношения · Обществознание и котики

Страница темы для GitHub Pages.

## Как залить
1. Загрузите в репозиторий всё содержимое этой папки (index.html, папки img/ и materials/).
2. Settings → Pages → Source: «Deploy from a branch», ветка main, папка / (root).

## Как поменять
- Логотип — замените файл img/logo.png (имя файла оставьте тем же).
- Цвета — блок `:root` в самом начале `<style>` в index.html.

## Страницы
- index.html — страница темы
- test-baza.html, test-pro.html — тесты с мгновенной проверкой (задания, ответы и пояснения записаны внизу файла, в `window.TEST`)
- chast-2.html — вторая часть со сверкой с эталоном
- assets/style.css — общее оформление, assets/test.js — логика тестов
